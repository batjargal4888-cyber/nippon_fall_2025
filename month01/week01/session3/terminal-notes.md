# Session 3 - Command Line Basics

## Why Terminal matters
- Terminal gives full control over the system
- Faster than GUI for developers
- Required for Git, servers, Docker, Node, etc.

## Must-remember commands
- pwd       -> shows current directory
- ls        -> list files
- ls -la    -> list all files with details
- cd        -> move between directories
- mkdir     -> create folder
- touch     -> create file
- mv        -> move / rename
- cp        -> copy
- rm        -> delete (permanent)

## Path basics
- /     -> root
- ~     -> home directory
- .     -> current directory
- ..    -> parent directory

## Safety rules
- Always run `pwd` before `rm`
- Terminal has NO undo
- Read error messages carefully

## Common errors
- No such file or directory     -> wrong path
- Permission denied             -> not allowed
- command not found             -> command doesn't exist

## My notes
- I learned that understanding the structure (command + options + target) makes new commands easier to figure out.
- Error messages give useful feedback and help me understand what went wrong and how to fix it.
- Compared to GUIs (Graphical User Interface), the terminal shows exactly what the system is doing and feels faster and more powerful once understood.
