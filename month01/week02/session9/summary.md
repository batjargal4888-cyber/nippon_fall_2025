# Day Summary - Pseudocode

## Core concept
**Pseudocode** is a way to describe an algorithm using plain, human-readable language, independant of any specific pragrammin language.

## Goal
To convert a flowchart into a clear written plan that:
- focuses on logic, not syntax
- is easy to understand
- can be translated into any pragramming language

## Key Structure Used
- `INPUT` - receive data from the user
- `SET` - assign values to variables
- `PRINT` - display output
- `IF / ELSE` - make decisions base on condition
- `FOR / WHILE` - repeat actions using loops

## Why Pseudocode matters
- Helps plan logic before writing code
- Makes algorithms easier to debug & improve
- Improves communication between developers
- Allows the same logic to be reused across different languages

## Key Takeaway
> Think in logic 1st, code 2nd.
> Pseudocode is the blueprint of a program.
