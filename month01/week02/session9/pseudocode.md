# Pseudocode Exercises - INPUT, SET, PRINT

These exercises focus on the 3 most basic programming actions:
- receiving input from the user (`INPUT`)
- assigning values to variables (`SET`)
- displaying results (`PRINT`)

Each exercise includes:
1. a short description (what the exercise is about)
2. the correct pseudocode solution

---

## Ex 1: Simple greeting

**Ex:**
Ask the user for their name & greet them.

**Pseudocode answer:**
INPUT name
SET message = "Hello, " + name + "!"
PRINT message

---

## Ex 2: Favourite color

**Ex:**
Ask the user for their color & respond with a message.

**Pseudocode answer:**
INPUT color
SET message = color + " is a really good choice!"
PRINT message

---

## Ex 3: Sum of 2 Numbers

**Ex:**
Ask the user for 2 integers & print their sum.

**Pseudocode answer:**
INPUT number1
INPUT number2
SET sum = number1 + number2
PRINT "The sum of these numbers is: " + sum

---

## Ex 4: Area of a Rectangle

**Ex:**
Ask for the length & width of a rectangle, then calculate its area.

**Pseudocode answer:**
INPUT length
INPUT width
SET area = length * width
PRINT "Rectangle area: " + area

---

## Ex 5: Age in Days

**Ex:**
Ask the user for their age in years & convert it into days.

**Pseudocode answer:**
INPUT age
SET days = age * 365
PRINT "You have lived approximately " + days + " days."

---

## Ex 6: Travel Plan

**Ex:**
Ask the user for a city they want to visit & display a travel message.

**Pseudocode answer:**
INPUT city
SET message = "Your next trip will be to " + city + "!"
PRINT message

---

## Ex 7: Area of a Circle

**Ex:**
Ask for the radius of a circle & calculate the area using π = 3.14.

**Pseudocode answer:**
INPUT radius
SET pi = 3.14
SET area = pi * radius * radius
PRINT "Circle area: " + area

---

## Ex 8: Fun Sentence

**Ex:**
Ask for an animal name & a verb, then create a sentence.

**Pseudocode answer:**
INPUT animal
INPUT verb
SET sentence = "A " + animal + " was " + verb + " ing."
PRINT sentence

---

## Ex 9: Convert Meters to Centimeters

**Ex:**
Ask for a length in meters & convert it to centimeters.

**Pseudocode answer:**
INPUT meters
SET centimeters = meters * 100
PRINT meters + " meters is equal to " + centimeters + " centimeters."

---

## Ex 10: Combine 1st & Last Name

**Ex:**
Ask for the user's last name & 1st name, then greet them using the full name.

**Pseudocode answer:**
INPUT lastName
INPUT firstName
SET fullName = firstName + " " + lastName
PRINT "Welcome, " + fullName + "!"
