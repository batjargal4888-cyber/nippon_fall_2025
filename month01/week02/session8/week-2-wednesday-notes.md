# Week 2 - Wednesday
## Visualizing Logic: Flowcharts

### 🎯 Daily Goal
Design algorithms & program logic using **flowcharts** to clearly visualize the flow of execution.

---

## 1. Algorithm Basics

- An algorithm is a **step-by-step solution** to a problem.
- It defines **logic and order**, not programmin syntax.
- Every program is based on an algorithm.

---

## 2. Purpose of Flowcharts

- Flowcharts visually represent **program logic**
- Help identify:
    - exection order
    - decision point
    - possible outcomes
- Flowcharts are **language-independent**

---

## 3. Standard Flowchart Symbols

- **Oval** - Start / End
- **Rectangle** - Process
- **Diamond** - Decision(Yes / No)
- **Parallelogram** - Input / Output
- **Arrow** - Flow direction

---

## 4. Logic Flow Principles

- Execution flows from **top to bottom**
- Decision nodes split the flow
- Only 1 path is followed at a time
- All paths should reach an **End**

---

## 5. Flowcharts & Programming

- Flowcharts map directly to:
    - conditionals (`if / else`)
    - loops
    - input/output
- Used befoer writing code to prevent logic errors

---

## 6. Why Flowcharts Matter

- Improve problem-solving skills
- Make logic easy to understand & explain
- Reduce bugs before coding

> If you can draw the logic, you can code it.
