# Week 02 - Monday
## Computer Architecture - Class Notes

### What we covered today
- Basic computer architecture & how a program runs
- Roles of **CPU, RAM, & Storage**
- Difference between **hardware** & **software**

### CPU (Central Processing Unit)
- Acts as the "brain" of the computer
- Executes instruction using **fetch-decode-executes** cycle
- Handles calculation & program logic

### RAM (Random Access Memory)
- Temporary memory used while programs are running
- Data is lost when the computer is turned off
- More RAM allows smoother multitasking

### Storage (HDD / SSD)
- Long-term data storage
- Stores operating system, program, & files
- SSD is faster than HDD

### How they work together
- Programs are stored in **Storage**
- When executed, they are loaded into **RAM**
- **CPU** processes data from RAM (not directly from Storage)

### In-class activities
- Checked personal computer specifications (CPU, RAM, Storage)
- Discussed common performance issus & their causes

### Key takeaways
- CPU, RAM, & Storage must work together
- Performance depends on all 3, not just CPU speed
- Understanding architecture helps explain how or lagging systems
