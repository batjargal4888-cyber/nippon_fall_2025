## 🗓 Practice Day 2 – Өнөөдөр юу хийх вэ?

Өнөөдөр **код бичих өдөр**.

### 🌐 Frontend (JavaScript)
- JavaScript ашиглан HTML текст өөрчилж сурна
- Style, class-ийг ON / OFF хийж сурна
- JS-ээр шинэ element (list, card) үүсгэнэ
- Dynamic list, delete button, card generator хийнэ

👉 Товчхондоо: **JS-ээр веб хуудсыг амьд болгоно**

### ☕ Java
- Strategy, Factory, Observer pattern-уудыг хэрэгжүүлнэ
- Нэг логикийг өөр өөр аргаар ажиллуулж сурна
- Real-world жишээ дээр pattern-уудыг хослуулна

👉 Товчхондоо: **Java кодоо илүү цэгцтэй, уян хатан болгоно**

🎯 **Зорилго:**  
Frontend дээр dynamic UI хийх,  
Java дээр design pattern-уудыг практикт ашиглах.
