# Week 17 – Баасан (Workshop Day)

## 🎯 Өнөөдрийн зорилго

Энэ workshop өдрийн төгсгөлд суралцагчид **Frontend** болон **Java** тал дээр бодитой, ажилладаг жижиг төслүүдийг бие даан угсарч, архитектурын үндсэн ойлголтуудыг практикт хэрэгжүүлж чаддаг болсон байна.

---

## 🧩 Frontend: Dynamic Content Generator

### Зорилго
- HTML form-оос хэрэглэгчийн оруулсан өгөгдлийг авах
- JavaScript ашиглан **динамик DOM элементүүд** үүсгэх
- Card / List / Table гэсэн **олон төрлийн контент** бий болгох
- Theme (Light / Dark / Colorful) логик хэрэгжүүлэх
- Үүсгэсэн контентыг **засах (Edit)**, **устгах (Delete)** боломжтой болгох
- Үүссэн элементүүдийн **тоо бодож харуулах**

### Сурах гол чадварууд
- `getElementById`, `querySelector`, `querySelectorAll`
- `createElement`, `appendChild`, `remove`
- `textContent`, `innerHTML`
- Event handling (`onclick`, `onkeydown`)
- Form validation ба UI feedback

---

## ☕ Java: Plugin System

### Зорилго
- **Interface-д суурилсан архитектур** ойлгох
- Plugin хэлбэрийн **өргөтгөх боломжтой систем** зохиох
- Нийтлэг логикийг `abstract class`-д гаргах
- Олон төрлийн plugin-уудыг нэг manager-аар удирдах

### Сурах гол чадварууд
- `interface` vs `abstract class`
- `extends` болон `implements`
- Generic method (`<T extends Plugin>`)
- Plugin registration / execution логик
- Runtime үед plugin шүүх, ажиллуулах
