# Week 18 - Wednesday (Theory 2)
## Summary

### JS (fetch API & Promises)
- `fetch()` is used to get or send data to a server
- `fetch()` always returns a **Promise**
- A promise has 3 states: pending, fulfilled, rejected
- `.then()` handles successful results
- `.catch()` handles errors
- `response.json()` converts server data into usable JS objects
- `fatch` can be used to load 1 item, a list, or send data with POST
- `Promise.all()` runs multiple requests at the same time

### Java (Composition)
- Composition means **Has-A**, not **Is-A**
- Composition is more flexible than inheritance
- Inheritance can cause bad design when used too much
- Composition allows changing behaviour at runtime
- Strategy Pattern is composition with interchangeable from outside
- DI reduces tight coupling & makes code easier to change

### Key Takeaways
- fetch + Promise = async data handling in JS
- Composition over Inheritance is a core OOP design rule
- Flexible code comes from combining objects, not extending everything
