### JS - Events
- Understand how the `addEventListener()` method works
- Learn how to use the Event object (`e`)
- Handle common events: `click`, `submit`, & `input`
- Use `preventDefault()` to stop default browser behavior
- Understand the difference between event bubbling & event capturing

### Java - Interface Advanced
- Implement multiple interfaces in a single class
- Define & use `default` methods in interfaces
- Add & use `static` methods in interfaces
- Understand interface constants (`public static final`)
- Learn the purpose & use cases of Marker Interfaces
